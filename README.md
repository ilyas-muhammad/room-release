# Room

Tiny but beast Mac cleaner. Clean junk, uninstall apps, find big files, clear developer leftovers.

## Download

Get the latest `Room-x.y.z.dmg` from [Releases](https://github.com/ilyas-muhammad/room-release/releases/latest), open it, drag Room to Applications.

- macOS 14 or later, Apple silicon and Intel
- Signed with Developer ID and notarized by Apple

Source code is private. This repo only hosts the builds.
